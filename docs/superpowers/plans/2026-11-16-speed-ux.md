# Speed and UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the gallery load fast on the phone (cache-stable links, revalidation, preview clips, background warm-up) and add muted lightbox videos, a 4/5/6 column toggle, a new speed curve and a lightbox Rename.

**Architecture:** `server.py` (stdlib only) gains a cache root outside the media folder with last-use tracking and a sweep, a `/preview/<id>` endpoint, `Last-Modified`/304 in `send_file`, a key-aware `Cache-Control`, a background warm thread and `POST /api/rename`. The static client switches its URLs to file keys, plays previews in the grid and adds the UI pieces.

**Tech Stack:** Python 3 stdlib (`http.server`, `unittest`), ffmpeg, plain HTML/CSS/JS (classic scripts sharing globals: `app.js`, then `select.js`).

**Spec:** `docs/superpowers/specs/2026-11-16-speed-ux-design.md`

## Global Constraints

- No new dependencies (Python stdlib only; no JS libraries, no build step).
- Never write anything inside the media folder (`BASE` and below) except the user's own renames/moves/deletes.
- Cache root: `Path(os.environ.get("XDG_CACHE_HOME") or Path.home() / ".cache") / "civit-rv"`; thumbnails in `thumbs/`, clips in `previews/`.
- Unused-for: `CACHE_MAX_AGE = 30 * 86400` seconds; touch on use at most once per `TOUCH_EVERY = 86400` s; sweep at startup and every 24 h.
- File key `k` = `file_key(item)` = `f"{int(item['mtime'] * 1000)}-{item['size']}"`, computed only on the server and sent to the client as `"k"` on every item of `/api/items` (Python and JS format whole-number floats differently, so the client never builds it). Keyed responses (query `k` equals the item's current key): `Cache-Control: public, max-age=31536000, immutable`. Unkeyed or mismatched: `no-cache`.
- Clip: 6 s, 480 px wide max, 24 fps, H.264 `libx264 -preset veryfast -crf 30 -pix_fmt yuv420p -movflags +faststart`, `-an`, start at 0.1 s; max 2 concurrent encodes (`PREVIEW_SLOTS = threading.Semaphore(2)`), timeout 120 s.
- Speed curve: `v <= 50: 10 * 0.45 ** (v / 50)`; else `4.5 * (1.5385 / 4.5) ** ((v - 50) / 50)` (v = slider 0..100; 10 s, 4.5 s, 1.5385 s).
- Columns: 4, 5, 6 only; default 4.
- Rename refusals and exact error strings: empty → `Name can't be empty`; bad chars → `Name can't contain / \ : * ? " < > |`; leading dot → `Name can't start with a dot`; > 255 bytes → `Name is too long`; conflict → `A file named <name> already exists`. Status 400 for these; 409 `Folder changed — reload to continue` for a stale `ver`; same CSRF checks as move/delete (`read_json_body`).
- Never run `server.py`'s `main()` on port 8765 (the live service) and never touch the live checkout or `~/.cache/civit-rv` of the live service from tests. Tests point `CACHE_DIR`/`PREVIEW_DIR`/`STATE_FILE` at temp folders. Browser checks use a scratch harness that imports `server` with temp paths on an ephemeral port.
- Run tests: `python3 -m unittest discover -s tests` from the worktree root.

## Review Focus

1. A rename racing with another tab's stale page: the `ver` guard must apply (409), and the renamed item's id must stay stable for the page that did it.
2. A video whose clip fails (corrupt file, audio-only mp4): the grid must still show something (server falls back to the original) and ffmpeg must not be re-run on every scroll.
3. The sweep must only ever delete inside the cache root, never follow symlinks out of it, and must not delete a clip being written (`*.tmp.*` files younger than a day are kept).
4. Keyboard in the rename sheet: arrow keys and Esc typed in the input must not navigate or close the lightbox underneath; Enter submits.
5. Changing columns while auto-scroll runs or while tiles are selected must not lose the selection or jump to the top.

**Interfaces:**
- Produces:

  - `file_key(item) -> str` returning `f"{int(item['mtime'] * 1000)}-{item['size']}"`; `api_items` adds `"k": file_key(it)` to each returned item.
  - `cache_key(item) -> str` (the sha1 currently inside `thumb_path`; reused by Task 2 and 3).

  - `media(idx, q)` / `thumb(idx, q)`: pass `immutable=(q.get("k", [""])[0] == file_key(item))`. `do_GET` passes `q`.
- Consumes: nothing new.
